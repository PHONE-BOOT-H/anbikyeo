# 안 비켜!

> 네가 비둘기다. 출근길 인파를 **최대한 늦게 피할수록** 점수. 배짱 몇 등급이냐.

한국인 전원이 아는 상황 — 칠 것 같은데 안 비키는 비둘기 — 를 뒤집은 배짱 측정 게임.

## 실행

```
python -m http.server 8321
# http://localhost:8321
```

빌드 없음. 정적 파일 서버면 뭐든 됨.

## 조작

- 모바일: 드래그 / PC: ←→ 방향키
- 행인을 아슬아슬하게 스치면 니어미스 보너스 + 배짱 콤보
- 부스러기 먹으면 추가 점수 (인파 쪽에 떨어진다)
- 밟히면 즉사. 점수 → 배짱 등급(9등급~무단횡단급) 카드 발급

## 구조

```
index.html      화면·오버레이
js/tuning.js    게임필 파라미터 전부 (튜닝은 여기만)
js/game.js      코어 루프·판정·렌더
js/sprites.js   픽셀 에셋 (전부 코드 드로잉)
js/audio.js     WebAudio 합성 사운드
js/card.js      공유 카드 1080×1350
js/main.js      UI 배선·코스메틱·저장
js/save.js      localStorage
```

의존성 0 (Galmuri 폰트 CDN 1개 예외). 서버·계정·트래킹 없음.
